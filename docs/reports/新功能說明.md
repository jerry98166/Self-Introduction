## 🎮 操作說明

### 右側浮動按鈕（從上到下）：
1. 🌙 主題切換（深色/淺色）
2. 🌐 語言切換（中文/英文）
3. 🎵 音樂播放器
4. 🖨️ 列印履歷
5. ⬆️ 回到頂部

### 打字遊戲使用方法：
1. 點擊「開始遊戲」按鈕
2. 在文本框中輸入顯示的文字
3. 正確字符顯示為綠色，錯誤為紅色
4. 60秒倒計時或完成全部文字後結束
5. 查看最終成績

### 成就解鎖條件：
- 自動追蹤您的網站互動
- 完成特定動作解鎖徽章
- 解鎖時顯示通知
- 成就永久保存在本地
