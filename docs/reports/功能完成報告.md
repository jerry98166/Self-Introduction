## 🚀 立即開始使用

### 步驟 1：開啟網站
```bash
# 直接用瀏覽器開啟
index.html

# 或使用本地伺服器
python -m http.server 8000
```

### 步驟 2：測試各項功能
1. 點擊右下角的機器人圖標 → 測試 AI 聊天
2. 點擊右下角的終端圖標 → 輸入 `help`
3. 導航欄點擊「留言板」 → 發送測試留言
4. 查看右上角的在線狀態
5. 觀察背景的 3D 動畫效果

### 步驟 3：訪問後台
```bash
# 開啟後台管理
admin.html

# 登入資訊
帳號：admin
密碼：admin123
```
