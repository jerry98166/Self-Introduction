# 🎉 新增進階功能說明

## 已完成的功能清單

### 1. 🤖 AI 聊天機器人
**位置**：右下角紫色機器人按鈕

**功能特點**：
- 訪客可以點擊右下角的機器人圖標打開聊天面板
- AI 可以回答關於你的技能、經歷、專案、學歷和聯絡方式的問題
- 提供快速問題按鈕，方便訪客快速提問
- 聊天記錄會自動保存到後台管理系統

**使用方式**：
1. 點擊右下角紫色機器人按鈕
2. 在輸入框輸入問題或點擊快速問題按鈕
3. AI 會即時回覆相關資訊

**可詢問的問題範例**：
- "你的技能有哪些？"
- "工作經歷"
- "有什麼專案作品？"
- "如何聯絡你？"

---

### 2. 💻 互動式終端機（駭客風格）
**位置**：右下角綠色終端機按鈕

**功能特點**：
- 黑底綠字的駭客風格終端機
- 支援多種指令查詢網站資訊
- 所有執行的指令都會記錄到後台
- 真實的終端機體驗

**可用指令列表**：
```bash
help       - 顯示所有可用指令
about      - 顯示關於我的資訊
skills     - 列出我的技能
projects   - 顯示我的專案
contact    - 獲取聯絡資訊
experience - 查看工作經歷
education  - 顯示學歷
clear      - 清空終端機
date       - 顯示當前日期時間
echo       - 輸出訊息
```

**使用方式**：
1. 點擊右下角綠色終端機按鈕
2. 輸入指令並按 Enter
3. 系統會顯示對應的資訊

**範例**：
```bash
visitor@portfolio:~$ help
visitor@portfolio:~$ about
visitor@portfolio:~$ skills
```

### 3. 🎨 Three.js 3D 背景動畫
**位置**：網頁背景

**功能特點**：
- 使用 Three.js 渲染 3D 幾何體
- 自動旋轉的扭結環面
- 半透明效果，不影響閱讀
- 增添視覺科技感

**效果**：
- 背景會顯示一個持續旋轉的 3D 圖形
- 與原有的粒子效果共同呈現
- 隨視窗大小自適應

---

### 4. 💬 訪客留言板
**位置**：導航欄新增「留言板」選項

**功能特點**：
- 訪客可以留下姓名、Email（選填）和留言
- 所有留言會保存在瀏覽器 localStorage
- 留言會即時顯示在右側
- 後台可以查看和管理所有留言

**使用方式**：
1. 點擊導航欄的「留言板」
2. 填寫姓名和留言內容
3. 點擊「發送留言」提交
4. 留言會立即出現在右側列表

---

### 5. 🟢 即時在線狀態
**位置**：網頁右上方（固定位置）

**功能特點**：
- 顯示你當前的在線/離線狀態
- 綠色圓點表示在線
- 紅色圓點表示離線
- 帶有呼吸動畫效果
- 每30秒自動更新狀態

**效果**：
- 訪客可以一眼看到你是否在線
- 增加互動性和真實感
- 支援中英文切換

---

### 6. 📊 後台管理系統
**訪問方式**：開啟 `admin.html` 文件

**登入資訊**：
- 帳號：`admin`
- 密碼：`admin123`

**功能特點**：

#### 📈 統計儀表板
- **總訪客數**：顯示網站訪客計數
- **訪客留言**：統計留言總數
- **AI 對話數**：追蹤聊天機器人對話次數
- **終端機指令**：記錄執行的指令數量

#### 💬 訪客留言管理
- 查看所有訪客留言
- 顯示訪客姓名、Email、時間
- 可以刪除單則留言
- 可以一鍵清空所有留言

#### 🤖 AI 聊天記錄
- 查看所有與 AI 的對話記錄
- 區分訪客提問和 AI 回覆
- 顯示對話時間
- 可以清空記錄

#### 💻 終端機指令記錄
- 以表格形式顯示所有執行過的指令
- 記錄執行時間
- 顯示模擬的訪客 IP
- 可以清空記錄

#### 🔧 管理功能
- **刷新數據**：重新載入所有統計資料
- **登出**：安全退出後台系統
- **響應式設計**：支援各種螢幕大小

## 🔒 資料儲存

所有資料都儲存在瀏覽器的 localStorage 中：
- `guestbook_messages`：留言板資料
- `chatbot_log`：AI 聊天記錄
- `terminal_log`：終端機指令記錄
- `visitor_count`：訪客計數

**注意**：清除瀏覽器資料會導致這些記錄遺失。如需長期保存，建議整合後端資料庫。
