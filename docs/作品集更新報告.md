## 視覺效果特色

### 顏色系統
- **主色調**：#667eea（紫藍色）
- **次色調**：#764ba2（紫色）
- **強調色**：#ec4899（粉紅色）
- **成功色**：#10b981（綠色）

### 陰影系統
- 卡片基礎陰影：`0 4px 20px rgba(0, 0, 0, 0.08)`
- 懸停陰影：`0 20px 40px rgba(99, 102, 241, 0.25)`
- 精選專案陰影：`0 25px 50px rgba(99, 102, 241, 0.35)`

### 動畫時序
- 快速過渡：0.3s
- 基礎過渡：0.4s
- 彈性函數：cubic-bezier(0.4, 0, 0.2, 1)
