# 🚀 快速開始指南

## 立即體驗新功能

### 1️⃣ 開啟網站
在瀏覽器中打開 `index.html`

### 2️⃣ 測試各項功能

#### 🤖 AI 聊天機器人
- **按鈕位置**：網頁右下角（紫色機器人圖標）
- **快速測試**：
  1. 點擊機器人按鈕
  2. 點擊「技能專長」快速問題
  3. 或輸入「你的經歷」提問

#### 💻 互動終端機
- **按鈕位置**：網頁右下角（綠色終端圖標）
- **快速測試**：
  1. 點擊終端機按鈕
  2. 輸入 `help` 查看所有指令
  3. 輸入 `about` 查看個人資訊
  4. 輸入 `skills` 查看技能列表

#### 📝 訪客留言板
- **位置**：導航欄 > 留言板
- **快速測試**：
  1. 點擊導航欄的「留言板」
  2. 填寫姓名：測試訪客
  3. 留言：這是一個測試留言
  4. 點擊發送

#### 🟢 在線狀態
- **位置**：網頁右上方固定位置
- **觀察**：查看綠色圓點呼吸動畫

#### 🎨 3D 背景動畫
- **位置**：整個網頁背景
- **觀察**：注意背景旋轉的 3D 幾何圖形

---

## 🔧 訪問後台管理

### 步驟：
1. 在瀏覽器中打開 `admin.html`
2. 輸入帳號：`admin`
3. 輸入密碼：`admin123`
4. 點擊登入

### 後台功能：
- 📊 查看統計數據（訪客數、留言數等）
- 💬 管理訪客留言（查看、刪除）
- 🤖 查看 AI 對話記錄
- 💻 查看終端機執行記錄
- 🔄 刷新數據
- 🚪 安全登出

## 🔑 重要提示

### 資料保存：
- 所有資料儲存在瀏覽器 localStorage
- 清除瀏覽器資料會導致記錄遺失
- 建議定期從後台匯出重要資料

### 瀏覽器兼容性：
- ✅ Chrome（推薦）
- ✅ Firefox
- ✅ Edge
- ✅ Safari
- ⚠️ 需要支援 Three.js 和 localStorage

### 最佳體驗：
- 使用最新版本瀏覽器
- 啟用 JavaScript
- 螢幕解析度 1920x1080 或更高

## 🐛 常見問題

### Q: 3D 背景沒有顯示？
A: 確認已載入 Three.js 庫，檢查瀏覽器控制台是否有錯誤

### Q: 聊天機器人或終端機打不開？
A: 重新整理頁面，確認 JavaScript 正常載入

### Q: 後台看不到資料？
A: 先在前台使用各項功能產生資料，再到後台查看

### Q: 留言沒有保存？
A: 檢查瀏覽器是否允許使用 localStorage
