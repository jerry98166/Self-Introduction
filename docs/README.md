## 🚀 快速開始

### 1. 開啟網站
```bash
# 直接雙擊
open index.html
```

### 2. 本地伺服器（可選）
```bash
# Python
python -m http.server 8000

# Node.js
npx http-server

# VS Code Live Server
右鍵 index.html → Open with Live Server
```

### 3. 訪問功能實驗室
點擊導航欄的 **"🧪 功能實驗室"** 按鈕

## 🎯 核心功能

### 🤖 AI / 機器學習（8 個）
- **語音對話助理** - Web Speech API 多語言對話
- **手勢辨識控制** - TensorFlow.js 手勢檢測
- **AI 面試模擬器** - 模擬技術面試
- 臉部表情互動、個人化導覽、情緒分析...

### 🔐 資安主題（7 個）
- **CTF 關卡系統** - 5 關資安挑戰（Base64, Caesar, SQL...）
- **數位足跡展示** - 完整瀏覽器指紋偵測
- **密碼強度測試器** - 即時強度分析與破解時間估算
- 蜜罐系統、假藍屏彩蛋、加密留言...

### 🎮 遊戲化互動（7 個）
- **RPG 角色卡** - 技能屬性視覺化（力量、智力、敏捷...）
- **網站尋寶遊戲** - 10 個隱藏寶藏等你發現
- **程式碼解謎遊戲** - 找 Bug 解鎖內容
- 技能對戰、打磚塊、時間膠囊...

### 📊 數據視覺化（6 個）
- GitHub 3D 貢獻圖 - Three.js 立體渲染
- 全球訪客地圖 - 3D 地球儀
- 學習時間熱力圖、技能成長曲線...

### 🎨 視覺體驗（6 個）
- WebGL 著色器背景 - GLSL 流體效果
- 動態天氣主題 - 根據位置改變主題
- 音樂視覺化 - Web Audio API 聲波動畫
- 滑鼠軌跡藝術、X光透視模式...

### 🛠️ 實用工具（5 個）
- **程式碼編輯器** - HTML/CSS/JS 即時預覽
- **API 測試工具** - 完整 HTTP 客戶端
- **正則表達式測試器** - 即時匹配與高亮
- **JSON 格式化工具** - 美化/壓縮/驗證
- 時區轉換工具

### 更多...

## 📝 自定義

### 修改個人資訊
編輯 `index.html` 中的個人資料

### 調整 RPG 數值
修改 `features/rpg-card.html` 的屬性值

### 更改 CTF 題目
編輯 `features/ctf-challenges.html` 的 `challenges` 陣列

### 添加新功能
1. 在 `features/` 建立新 HTML
2. 在 `lab.js` 註冊功能
3. 在 `lab.html` 添加卡片
