## 💡 使用技巧

### 1. 瀏覽器相容性
- **推薦瀏覽器：** Chrome, Edge, Firefox
- **語音功能：** 需要 Chrome 或 Edge
- **WebGL 功能：** 需要支援 WebGL 的現代瀏覽器

### 2. 權限設定
某些功能需要瀏覽器權限：
- 🎤 **麥克風：** 語音對話助理
- 📹 **攝像頭：** 手勢辨識、臉部表情
- 📍 **位置：** 天氣主題、訪客地圖

### 3. 本地儲存
以下功能使用 LocalStorage 儲存資料：
- CTF 挑戰進度
- 尋寶遊戲進度
- 留言板內容
- 個人設定

**清除資料：** 在瀏覽器開發者工具中清除 LocalStorage

### 4. 快捷鍵
- **程式碼編輯器：** Ctrl+Enter 執行代碼
- **終端機：** 輸入 `help` 查看所有命令

## 🔧 自定義與擴展

### 修改內容
1. **個人資訊：** 編輯 `index.html`
2. **RPG 角色卡：** 編輯 `features/rpg-card.html` 中的數值
3. **CTF 題目：** 修改 `features/ctf-challenges.html` 中的 `challenges` 陣列

### 添加新功能
1. 在 `features/` 資料夾建立新的 HTML 檔案
2. 在 `lab.js` 的 `features` 陣列中註冊
3. 在 `lab.html` 中添加功能卡片

### 樣式調整
- 修改各個 HTML 檔案中的 `<style>` 標籤
- 統一樣式可以提取到 `styles.css`

## ❓ 常見問題

### Q: 語音助理無法使用？
**A:** 確認：
1. 使用 Chrome 或 Edge 瀏覽器
2. 允許麥克風權限
3. 必須使用 HTTPS 或 localhost

### Q: 某些功能顯示「不支援」？
**A:** 不同瀏覽器支援度不同，建議使用最新版 Chrome。

### Q: 如何清除遊戲進度？
**A:** 開啟瀏覽器開發者工具（F12）→ Application → Local Storage → 清除對應項目

### Q: 可以商用嗎？
**A:** 這是個人作品集，可自由修改和使用。部分外部資源（如字體、圖示庫）請確認授權。
