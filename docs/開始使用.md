## 🛠️ 本地運行（可選）

### 方法 1：Python
```bash
python -m http.server 8000
# 訪問 http://localhost:8000
```

### 方法 2：Node.js
```bash
npx http-server
# 訪問 http://localhost:8080
```

### 方法 3：VS Code
1. 安裝 "Live Server" 擴充功能
2. 右鍵 `index.html` → "Open with Live Server"

## ❓ 常見問題

**Q: 語音功能無法使用？**  
A: 使用 Chrome/Edge 瀏覽器並允許麥克風權限

**Q: 如何修改個人資訊？**  
A: 編輯 `index.html` 和 `features/rpg-card.html`

**Q: 如何清除遊戲進度？**  
A: 開啟瀏覽器開發者工具 (F12) → Application → Local Storage → Clear
